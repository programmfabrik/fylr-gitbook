## Important

* **This release contains important security fixes. We strongly advise updating every instance as soon as possible.** The fixed issues also exist in earlier releases, so all instances should be updated, above all those that are reachable from the internet. Installing 6.35.5 is all it takes: there is no database migration, no re-index and no configuration change, and the web frontend is the same as in 6.35.4.
