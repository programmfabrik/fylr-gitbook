## Important

* **This release contains important security fixes. We strongly advise updating every instance as soon as possible.** The fixed issues also exist in earlier releases, so all instances should be updated, above all those that are reachable from the internet. Installing 6.35.5 is all it takes: there is no database migration, no re-index and no configuration change. The web frontend brings a few fixes, see **Web frontend**.

## Web frontend

### Fixed

* Printing with the PDF creator no longer hangs when a nested field displayed as a table has another nested field inside. When the PDF creator shows an error of its own, the generic "PDF server" error no longer shows on top of it. [3925a9f4c] [94590f379]
* Search: the text being typed is no longer wiped or cut into search tokens by searches the user did not start, like late filter requests or the refresh after saving a new record. A linked object field keeps its text when moving into the suggestions or switching windows. [bc4da4f17]
* Expert search: a field that the selected object types do not have no longer makes the search hang, and a publishing filter with only one date no longer sends an empty end date. [e8bdcd716]
* Group editor: typing into a field ticks it, so the value is no longer dropped on save. With "Remove all", the input of nested fields, tags and rights is hidden and not sent, the editor can be closed after the warning, and "Remove all" on tags with tags selected no longer fails. [80dbb4434] [a221e240c]
* Video previews: a rendition with a watermark, like "Public Watermark", is no longer taken for a clean one, so the clean preview is shown. [d3e90d1fc]
* CSV importer: a column named like the parent field, like `_id_parent` from a CSV export, no longer breaks the import mapping. A GeoJSON field reads a value of the Location custom data type, as the CSV export writes it, as a point with its display name. [648ff37c5] [0650e7b94]
* Editor: in a nested field edited in a popup, a new row can be moved with the drag handle before the record is saved. [192a3202b]
