## Important

* **The docker images come with security updates. We advise updating every instance.** The images contain the current Brotli library and Node.js 24.22.2. An installation without the docker images updates Brotli and Node.js through its own package sources. Installing 6.35.3 is all it takes: there is no database migration, no re-index and no configuration change, and the web frontend is the same as in 6.35.2. [5d0b9be79]

* **Rights passed on through a collection follow the object types of the grantable right.** A collection that relied on a `_grantable` pool right for other object types can turn invalid at its next check. See "Rights passed on through a collection follow the object types of the grantable right" under **Fixed**. [e9d1cc8d9]

## fylr core

### Fixed

#### Rights passed on through a collection follow the object types of the grantable right

A `_grantable` pool right that lists object types passes on records of these object types only. For records of other object types, `POST /api/v1/collection/push/{id}` and a save of a collection's or pool's `_acl` can answer `202` with `allow_invalid_acl`, and a save of the record `202` with `confirm_collection_policy`. Existing collections stay as they are until one of these checks runs. [e9d1cc8d9]
