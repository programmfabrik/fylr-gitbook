# Release v6.35.0

**Not released yet.** These notes describe work that has landed on `main` but has

## Highlights

* **Gaussian splats and 3D meshes** get previews rendered by fylr and open in a 3D viewer. → [360° and 3D viewers](../../for-users/additional-features/README.md#id-360-and-3d-viewers)

* **360° photos and videos** are recognized and open in a 360° viewer to look around in. → [360° and 3D viewers](../../for-users/additional-features/README.md#id-360-and-3d-viewers)

* **A video editor** in the variant editor trims, crops, rotates, mirrors, mutes and colour-corrects a video and picks its thumbnail frame; it needs the `video_editor` license capability. → [Video Editor](../../for-users/additional-features/custom-renditions-and-crop-tool.md#video-editor)

* **Multi-page TIFFs** open page by page and OCR reads every page; **audio** plays with its own transport bar and waveform. → [360° and 3D viewers](../../for-users/additional-features/README.md#id-360-and-3d-viewers)

* **The plugin marketplace** adds plugins from an in-app catalog, dependencies first. → [Plugin Marketplace](../../for-administrators/plugin-manager/README.md#plugin-marketplace)

* **The change history marks nested rows one by one**: removed rows red, added rows green, changed rows as modified. → [Highlighting Changes](../../for-users/additional-features/change-history.md#highlighting-changes)

* **The query language searches the change history**, and `$current_user` makes a saved search find the changes of whoever opens it. → [Query Language](../../for-users/search-and-filter/query-language.md#change-history)

* **Dates are found by the full-text search** in their ISO form, their rendering in each database language and their year. → [Searching for dates](../../for-users/search-and-filter/full-text-search.md#searching-for-dates)

## Important

* **The upgrade migrates the database and runs a full, blocking re-index.** Until the new index has switched in, only `/inspect/` answers; allow time on a large instance. → [Re-index](../../for-system-administrators/inspect/system.md#re-index)

* **Everyone is logged out once.** fylr's own OAuth2 server replaces every stored token: browsers log in again, scripts fetch a new token. The `openid` scope is rejected. → [OAuth2](../../for-developers/api/oauth2.md)

* **Execserver and fylr must be upgraded together.** An execserver of another version exchanges no jobs, and several execserver settings are gone. → [Updating the execserver to 6.35](../../for-system-administrators/installation/updating-the-execserver-to-6.35.md)

* **Video encodes no longer take every core.** An encode runs FFmpeg with the CPUs the execserver has free when it starts, often one while the other versions of an upload are produced; `FYLR_CONVERT_VIDEO_MP4_THREADS` sets the thread count of every MP4 encode. → [Long videos encode with one thread](../../for-system-administrators/configuration/performance-tuning.md#long-videos-encode-with-one-thread)

* **Self-installations need Ghostscript.** Without Docker, on Linux, macOS or Windows, fylr renders EPS, AI and PS with `gs` itself. The `easydb-plugins` folder is no longer in the archives, so remove its entries from `plugin.paths`; building from source needs Go 1.27. → [Updating a self-installation to 6.35](../../for-system-administrators/installation/README.md#updating-a-self-installation-to-6.35)

* **A proxy in front of fylr must be listed** in `fylr.trustedProxies`, which is empty by default; otherwise IP-filtered groups, the login lockout and the audit log see the proxy's address. → [Trusting a proxy for the client address](../../for-system-administrators/installation/linux-docker-compose/proxy-and-fylr.md#trusting-a-proxy-for-the-client-address)

* **The easydb plugins no longer ship with fylr.** Enabled plugins with a marketplace successor are converted on upgrade, so the instance must reach the plugin sources. → [Disk to URL plugin migration](../../plugins/disk-to-url-migration.md)

* **The migration tool `fylr restore` needs data extracted with `fylr backup` of 6.35.0 or newer**; the source instance may be older. It also needs a login with `system.root`, and `--file-api-access-token` is removed. → [Insert payloads (fylr restore)](../../for-system-administrators/migration/restore.md#data-extracted-with-fylr-backup-6.35.0-or-newer)

* **Producing from videos, and with it the video editor, needs the `video_editor` license capability**; a license issued before has to be re-issued with it. → [/produce](../../for-developers/api/endpoints/eas/produce.md#image-and-video-parents)

* **Hierarchies with individual record permissions need two new permissions**: until "Create or Attach Child Records" and "Detach Child Records" are set, only `system.root` and a record's owner hang records beneath it. Setting them on the top-level records covers the whole hierarchy. → [Record Permissions](../../for-administrators/permissions/record-permissions.md)

* **Uploading into a collection with only "Create Records Directly in Collection"** needs complete upload settings and an owner who may create the records. → [Who can upload](../../for-users/quick-access/collections-and-presentations.md#who-can-upload)

* **Deleting a group needs "View, Edit & Delete Group"** on it; changing its authentication mappings needs "Add Users to Group" or "Remove Users from Group". → [Groups](../../for-administrators/permissions/groups.md#permissions)

* **`/api/v1/eas` urls are signed** like `/db` and search urls. A client that appends to such a url inserts before the signature, or asks for unsigned urls with `file_url_expire=0`. → [/api/v1/eas](../../for-developers/api/endpoints/eas/README.md)

* **A rejected access token is `401 InvalidToken` on every endpoint**, also on `/user/session` and `/oauth2/refresh`, which answered `400`. → [OAuth2](../../for-developers/api/oauth2.md)

* **Saved file-handling configurations are migrated** but do not learn the new `ps` extension: enable it in the image class and its renditions, or reset the class to the default. → [PostScript documents](#postscript-documents)

* **`Generic XYZ Profile` and `Generic Lab Profile` are gone**; a custom version preset naming one no longer saves. → [Custom Version Presets](../../for-administrators/readme/file-worker/custom-version-presets.md#color-space-and-color-profile)

* **A pool's standard masks decide what is indexed**, not only what a search returns; changing them re-indexes the pool's records after confirmation. → [Masks](../../for-developers/concepts/masks.md#standard-masks-decide-what-is-indexed)

* **XSLT stylesheets work on the exported XML alone.** A stylesheet of an export, a deep link or an OAI/PMH format loads no other document, file or URL (`document()`, `doc()`, `unparsed-text()`, `xsl:include`, `xsl:import`) and cannot use `xsl:result-document`; lookup tables go into variables of the stylesheet itself. → [XSLT File](../../for-administrators/readme/export-and-deep-links.md#xslt-file)

* **Stricter validation on save**: recipe values outside their range, field type changes checked against the conversion matrix with or without data, and a saved data language's code is read-only. → [File production settings](#file-production-settings), [Datamodel editing](#datamodel-editing), [Languages](../../for-administrators/readme/languages.md#language-code-bcp-47)

* **New defaults**: `X-Frame-Options: SAMEORIGIN` on every response, so a portal embedding fylr lists its origin in `fylr.services.webapp.frameAncestors`; credentialed CORS only for configured origins. → [HTTP and HTTPS](../../for-system-administrators/configuration/http-and-https.md#security-headers-and-cors)

* **Removed**: the `fylr pdf2pages` subcommand; the `X-Easydb-Base-Schema-Version` and `X-Easydb-User-Schema-Version` headers, use `X-Fylr-Cache-ID` for cache invalidation [0fe459288]; the `plugin.webfrontend.readme` and `version` manifest keys; `Access-Control-Allow-Private-Network`.

* **For files uploaded before the upgrade**: a *resync* adds the [video timeline frames](#a-video-produces-preview-frames-for-the-player-timeline) and classifies [PostScript files](#postscript-documents); a *resync with metadata* reads [360° markers](#id-360-media-are-recognized), [stream lists](#video-and-audio-streams-in-the-technical-metadata) and the [EXIF creation date](#a-camera-images-creation-date-is-its-exif-date); a *re-produce* renders [3D assets](#id-3d-assets), [EPS and AI](#eps-and-ai-render-with-ghostscript) and [percentage watermarks](../../for-administrators/readme/file-worker/preview-configuration.md); re-run the OCR recipe on [multi-page TIFFs](#a-multi-page-tiff-gets-a-pages-version-and-ocr-reads-every-page). Full-text dates and pool standard masks come with the upgrade's re-index. → [Files](../../for-system-administrators/inspect/files.md#file-actions)

## fylr core

### New

#### Base fields only group edits

`POST /api/v1/db/{objecttype}?base_fields_only=1` changes the tags or pools of records editable through different masks in one request. → [/api/v1/db](../../for-developers/api/endpoints/api-db.md#base-fields-only-group-edits) [4a26c76c3]

#### OAI/PMH

The `easydb` metadata format can be switched off in the base configuration, `ListSets` lists only sets with harvestable records, and pool sets such as `set=pool:1:4` are harvested. → [OAI/PMH](../../for-administrators/oai.md) [dace631be]

#### Search

* A `term` aggregation nests further aggregations below each of its buckets. → [/api/v1/search](../../for-developers/api/endpoints/api-search.md) [dace631be]
* A collection search finds the collections that hold a record of another instance by its global object id, `_remote_objects`. → [collection](../../for-developers/system-data-types/collection.md#in-the-api) [c9e87f477]
* `_changelog.date_deleted` sorts records by deletion time, so the trash lists them in the order they were deleted. → [Sorting](../../for-developers/search-requests.md#sorting) [9e1af946d]

#### The query language searches the change history and knows the current user

`_changelog == ?( … )` finds records by their change history — user, operation, date and comment of the same change — and `$current_user` stands for the logged-in user, so a saved search finds the changes of whoever opens it. → [Query Language](../../for-users/search-and-filter/query-language.md#change-history) [846307de2] [1f946caa3] [54d346a22]

#### IIIF manifests

The base configuration sets the manifest's `rights` URL and the mask that fills its metadata, and the required statement and rights take `%<objecttype>.<field>%` placeholders. → [Export & Deep Links](../../for-administrators/readme/export-and-deep-links.md#iiif-placeholders) [4d8d9bfe0]

### Improved

#### No access token in the browser's urls

`/api/v1/eas` signs its file urls like `/db` and search; exports, backups and the event stream no longer need the token in the url either. `?access_token=` keeps working. → [/api/v1/eas](../../for-developers/api/endpoints/eas/README.md), [/api/v1/export](../../for-developers/api/endpoints/api-export.md), [/api/v1/event](../../for-developers/api/endpoints/api-event.md) [ddc0f6e98] [add7bde1f]

#### Dates are searchable in the full text

A date field with the mask's full-text option is found by its ISO form, its rendering in each database language and its year. → [Searching for dates](../../for-users/search-and-filter/full-text-search.md#searching-for-dates) [6585e4023]

#### Masks below the line in a pool are no longer indexed

A record is indexed only under the standard masks of its pool, and changing them asks to re-index the records concerned. → [Masks](../../for-developers/concepts/masks.md#standard-masks-decide-what-is-indexed), [Pools](../../for-developers/concepts/pools.md) [f33fe8206]

#### A user record names the groups the user is automatically in

The user API and the user manager list rule-based memberships such as "Alle Benutzer". → [/api/v1/user](../../for-developers/api/endpoints/api-user.md#automatic-groups) [0f73ad852]

#### Deleting records that other records link to

Where the deletion dialog or a `delete_objects` task unlinks, deleting a record also removes the nested-table rows in other records whose required link points at it, and a task no longer stops on links between records of its own result. → [Deleting Records](../../for-users/asset-records-management/deleting-records.md#deleting-referenced-records), [Background Tasks](../../for-users/additional-features/background-tasks.md#delete_objects) [819d484c7] [ee507448a]

#### API documentation

Error responses document the code the server returns, and the search request lists the fields every search domain accepts. → [API endpoints](../../for-developers/api/endpoints/README.md) [b28c7f1cf] [c9e87f477]

#### Faster loading and saving

Linked and historical reads reuse lookups within a request, and saving into a hierarchical object type no longer slows down as it fills up. [4a26c76c3] [5d8a11644] [d40f2c216]

#### Requests no longer wait for each other

Under load, a request could wait seconds before fylr started working on it, without the wait showing in the log; most of all with `fylr.db.maxIdleConns: 0`, where uploads now run about twice as fast. [3be87196b]

#### Dependencies

All direct Go dependencies are up to date, `grpc` and `otel` past two Go vulnerability database entries, and every build checks that database. [d671692707] [70c43c8c9d] [93a8b881ba] [ade2c7f20] [6120559a28]

### Fixed

A re-index no longer breaks on objects with millions of versions and counts as done only once the new index is searchable, and search no longer loses an object's latest update. → [Re-index](../../for-system-administrators/inspect/system.md#re-index) [07a0ddcb5e] [61fe9d02be] [2c327bd3a]

#### Collection upload settings and pin codes

#### The change history and the changelog_range search

The DELETE entry of the change history names who deleted the record, and a `changelog_range` search finds deletions by user and compares its dates in UTC. → [Building a Search Request](../../for-developers/search-requests.md) [10862b72c] [846307de2]

## Authentication and security

### New

#### Two record permissions decide who may hang records beneath a record

In a hierarchical object type with individual permissions per record, "Create or Attach Child Records" on the parent is needed to create or move a record beneath it, and "Detach Child Records" to move it away. Both are inherited down the hierarchy, and the parent's owner has them. A save without `_private_acl` keeps *Ignore permissions for superordinate records*. → [Record Permissions](../../for-administrators/permissions/record-permissions.md), [Permissions](../../for-developers/concepts/permissions.md) [8703b9777]

#### Collection and group permissions

* "Create Records Directly in Collection" creates records on behalf of the collection's owner when the upload settings are complete and the record matches them; everyone else needs their own create permission and "Add Records to Collection". → [Who can upload](../../for-users/quick-access/collections-and-presentations.md#who-can-upload) [931b0b5b9]
* Deleting a group and changing its authentication mappings need the matching group permissions. → [Groups](../../for-administrators/permissions/groups.md#permissions) [931b0b5b9]
* Changing a permission that a shared collection relies on asks for confirmation. → [Setting Up Collection Sharing](../../help/tutorials/for-administrators/setting-up-collection-sharing.md#changing-permissions-that-shared-collections-rely-on) [931b0b5b9]

### Improved

#### fylr has its own OAuth2 authorization server

It replaces the fosite library and keeps the wire format and the grants. No `id_token` is minted, and `scope=openid` fails with `invalid_scope`. A rejected token is `401 InvalidToken` on every endpoint, and responses under `/api/oauth2` are no longer compressed. → [OAuth2](../../for-developers/api/oauth2.md) [6e1fc2bae] [3a962bd35] [1baae56a2]

#### Client address behind a proxy

fylr takes the client address from the connection and uses `x-real-ip` / `x-forwarded-for` only from peers in `fylr.trustedProxies`; loopback is always trusted. → [Trusting a proxy for the client address](../../for-system-administrators/installation/linux-docker-compose/proxy-and-fylr.md#trusting-a-proxy-for-the-client-address), [fylr.example.yml](../../for-system-administrators/configuration/fylr.example.yml.md) [193b673297] [a6577ad31]

#### Security headers and CORS

Every response carries security policy headers, `X-Frame-Options: SAMEORIGIN` by default. Credentialed CORS answers only fylr's own origin, `loginAllowRedirects` and registered OAuth2 clients, and the `loginAllowRedirects` default includes `https://*.web.fylr.io`. → [HTTP and HTTPS](../../for-system-administrators/configuration/http-and-https.md#security-headers-and-cors) [e9e8a7c6d] [00d56743c] [0fe459288] [ad272dc93] [024304e14]

### Fixed

#### Share links and the ?login flag

A `?login` share link asks for credentials again, and readers who may already read the collection go straight in. → [Setting Up Collection Sharing](../../help/tutorials/for-administrators/setting-up-collection-sharing.md) [bcc568bf2] [409229016]

#### SAML Single Logout works with IdPs that require signed logout messages

Logout requests and responses are signed, incoming ones verified, and the POST binding is used where the IdP offers only that. → [SAML](../../tutorials/auth/saml/README.md#single-logout) [745d1e38b]

#### The root form of the password logs in LDAP and SSO users again

`<root login>/<root password>` as the password logs in LDAP, SSO and email users again. [67377ec0c]

#### Security fixes

Fixed security bugs. [f2b51eafd] [0aa8aa1b2] [4cdacfa25] [8d4108e06] [931b0b5b9] [e09a11b56] [835c486bc] [6172a1a5e] [af813b408] [dca4f25f4]

## Files and media

### New

#### A video produces preview frames for the player timeline

Videos get a `pages` version with frames and contact sheets for the player's timeline; existing videos get it on resync. `fylr convert --format pages.zip` replaces `fylr pdf2pages`. → [The pages version](../../for-developers/file-worker.md#the-pages-version-many-images-in-one-version) [4eebf3c25, 68a54b280, 3072e750c]

#### A multi-page TIFF gets a pages version, and OCR reads every page

A multi-page TIFF opens page by page and OCR reads every page; existing files need a resync and a re-run of the OCR recipe. → [The pages version](../../for-developers/file-worker.md#the-pages-version-many-images-in-one-version), [Search in Text of Images or Office Files](../../help/tutorials/for-administrators/search-text-in-images-or-office-files.md) [17fc71f7a] [d794f24fb]

#### PostScript documents

A `.ps` file renders like EPS and AI, with a `pdf` of every page and a paged view, and a Type 1 font program shows a specimen of the font. Files uploaded before are classified on resync. → [File worker](../../for-administrators/readme/file-worker/README.md) [04daf1e8d] [32ba5394d]

#### 3D assets

Gaussian splats and polygon meshes get the file class `3d`, previews rendered by fylr and a version for the 3D viewer; more 3D formats are accepted and classified. → [3D assets](../../for-developers/file-worker.md#id-3d-assets) [7d5129cf2]

#### 360° media are recognized

Spherical videos and panoramas carry `technical_metadata.projection_type`, and so do versions that keep the full frame. → [Metadata extraction](../../for-developers/file-worker.md#id-6.-metadata-extraction) [6ea606aef] [44120f79b]

#### Produce new versions from videos

`POST /eas/produce` trims, mutes, rotates, mirrors, crops, scales and colour-corrects a video into MP4, MOV or M4V, given the `video_editor` license capability; `webp` images can be produced from too. → [/produce](../../for-developers/api/endpoints/eas/produce.md) [f4be96604] [ad91e66c8] [a857725c6]

#### Download dialog options are grantable per user and group

The **Download Options** right grants the file name, file variants and custom rendition sections of the download dialog separately; the upgrade turns all three on for everyone with the download right. → [Downloading](../../for-users/download-and-export/downloading.md#download-options) [52d48fd52]

#### Transparent images

`technical_metadata.alpha` marks a file with an alpha channel, and the zoom keeps a PNG's transparency. → [Technical Metadata](../../for-developers/system-data-types/file.md#technical-metadata) [2ea62b3006] [920577b09]

### Improved

#### Video and audio streams in the technical metadata

`technical_metadata` lists every video and audio stream with codec, size, duration, frame rate and language. → [Technical Metadata](../../for-developers/system-data-types/file.md#technical-metadata) [3072e750c]

#### Colour space and colour profile of a custom version

A colour space an ICC profile can express is converted through that profile, an image without an embedded profile is converted as sRGB (CMYK pixels as ISO Coated v2), colour space and profile have to agree, and the generic XYZ and Lab profiles are gone. → [Custom Version Presets](../../for-administrators/readme/file-worker/custom-version-presets.md#color-space-and-color-profile) [920577b09] [8da3c2eee]

#### Audio conversion and snippets

The audio converter writes `m4a`, `mp3` or `aac` at 128–320 kbit/s with cover art, and an audio snippet can be seeked in and played again. → [Preview Configuration](../../for-administrators/readme/file-worker/preview-configuration.md), [Audio snippets](../../for-developers/fileversions/recipes-available-via-url.md#audio-snippets) [a59edb9cb, 97dba9a25] [fcd58d259]

#### Paths inside a ZIP

ZIP paths work in every storage location, S3 included, with `asset_show`, and listings report real modification times. → [Paths inside a ZIP](../../for-developers/api/endpoints/eas/download.md#paths-inside-a-zip) [35e6bb46f] [b52fe9712]

#### File production settings

Saving the production settings refuses a recipe value the recipe cannot use and names the setting, and the default configuration writes identical versions only once. → [Preview Configuration](../../for-administrators/readme/file-worker/preview-configuration.md) [68a54b280] [e7a2f4bc1] [7fbf4ffd1]

#### Metadata mapping

`/inspect/events/<id>/` shows a recipe run's command line and output, a recipe can report warnings, and the mapping task tags the records it could not update so the next run skips them. → [Metadata Mapping](../../for-administrators/metadata-mapping.md#warnings-from-a-recipe), [Background Tasks](../../for-users/additional-features/background-tasks.md) [8a933ae31] [ccbfc6d03] [0d96a8076] [eed0d7ca7]

#### EPS and AI render with ghostscript

EPS and AI rasters render from the original with ghostscript, the SVG version only where a browser can open it, and Illustrator files older than version 9 convert; existing files keep their versions until re-produced. → [Metadata extraction](../../for-developers/file-worker.md#id-6.-metadata-extraction) [62205dcf7] [2ea62b3006]

## Execserver

### New

#### Execserver commands can request temporary CPU allocations

A command may borrow CPUs from the shared pool while it runs a parallel subprocess, as `fylr convert` does around FFmpeg; long jobs wait while borrowed CPUs are held, so the slots kept for short jobs stay free. A set `FYLR_CONVERT_VIDEO_MP4_THREADS` is the thread count of every MP4 encode, whatever the pool has free. → [Execution limits](../../for-developers/execserver.md#execution-limits), [Long videos encode with one thread](../../for-system-administrators/configuration/performance-tuning.md#long-videos-encode-with-one-thread) [bebc44b55] [24f417b1b]

### Improved

#### Execserver scheduling and execution limits

fylr pushes jobs onto free execserver slots. The execserver runs one pool of slots for all services, keeps slots for short jobs, caps a service with `maxSlots`, and stops commands that exceed their memory or stop making progress. Waitgroups and the `/job/<service>` address filter are gone. → [Execserver](../../for-developers/execserver.md), [Updating the execserver to 6.35](../../for-system-administrators/installation/updating-the-execserver-to-6.35.md), [performance tuning](../../for-system-administrators/configuration/performance-tuning.md) [dc23ded29] [c7cc099cd] [58bf5cd15] [d9abc6263] [8d92737db]

#### A fleet behind a load balancer is used whole, and the file dispatcher fills it

Behind one load-balanced address fylr finds every pod within a second and keeps looking for new ones, and the file dispatcher sizes its admission by what the execservers absorb. → [The file worker](../../for-developers/file-worker.md), [slot broker white paper](../../for-developers/concepts/white-papers/execserver-slot-broker.md) [c0af74da7]

#### An execserver keeps its name and its job counters across a restart

The topology page shows an execserver by its hostname, and its done and failed counts survive a restart. → [Fleet topology](../../for-system-administrators/inspect/system.md#fleet-topology) [68b1cb13b] [275178562]

#### A stopped fylr's file jobs come back within a minute

When a fylr server is killed, crashes or runs out of memory, the others put its file jobs back into the queue within a minute instead of after 15 minutes, and the file queue in `/inspect` names the fylr server processing each job. → [File Queue](../../for-system-administrators/inspect/files.md#file-queue) [31ab1f588]

### Fixed
