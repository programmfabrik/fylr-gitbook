# Keyboard Shortcuts

Most shortcuts combine a key with an **action key**. Each of these keys works as the action key:

* **Windows and Linux:** Ctrl or Alt
* **macOS:** Command (⌘), Control or Option

A shortcut runs only what the user account has the permission for, for example creating or exporting records.

| Shortcut | Function | Where and how to use |
| --- | --- | --- |
| **Action key + N** | Create new records | Anywhere in fylr. Opens the same dialog as **New records...** in the menu. |
| **Action key + S** | Save | In the editor. |
| **Action key + A** | Select all records | In the main search, with the focus in the results, for example after clicking a record. In a text field, it selects the text instead. |
| **Action key + D** | Download the selected records | In the main search, with at least one record selected. Opens the same dialog as **Download...** in the context menu. |
| **Action key + Shift + E** | Export the selected records | In the main search, with at least one record selected. Opens the same dialog as **Export...** in the context menu. |
| **Action key + E** | Open the expert search | In the main search. |
| **Ctrl + Shift + F**, on macOS **⌘ + Shift + F** | Open in fullscreen | From version 6.36.0, in the main search. With the focus in the results, it opens the selected record in fullscreen; with several records selected, the fullscreen shows only these. With the focus in the detail on the right (click anywhere in it), it opens the shown record, like the fullscreen button of the detail, and the detail stays open. A record without a file has no fullscreen button in the detail, so the shortcut does nothing there. In the fullscreen, the arrow keys go to the previous and next record, and **Esc** or **X** closes it. The setting **Use fullscreen for records** stays as it is. |
| **Arrow keys** | Go to the previous or next record | In the results of the main search, after clicking a record: left and right in the **Standard** view, up and down in the **Text** and **Table** views. |
| **Action key + A, C, X, V** | Select all, copy, cut and paste search elements | In the search bar. **Backspace** or **Delete** removes the selected search elements. See [Working with Search Elements](search-and-filter/README.md#working-with-search-elements). |

Some combinations belong to the browser or the operating system, for example Ctrl + N opens a new browser window. If the browser reacts instead of fylr, use another action key, for example Alt + N.

The crop tool and the video editor have shortcuts of their own, each lists them in its help sheet. See [Custom Renditions & Crop Tool](additional-features/custom-renditions-and-crop-tool.md).
