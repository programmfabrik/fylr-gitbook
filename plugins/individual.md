# Individual plugins

Eight plugins have a page of their own below. They are the ones administrators ask about most often — not a complete list, and not a ranking.

{% hint style="info" %}
**Every other plugin documents itself.** A plugin ships a `README.md` next to its manifest, and from fylr **6.35.0** the plugin manager shows it on the plugin's **README** tab — the same text the [marketplace](../for-administrators/plugin-manager/README.md#plugin-marketplace) shows as **more information** before you install. That is the documentation for the other plugins in the [Plugin Overview](overview.md); there is no second copy of it here to fall out of date.
{% endhint %}

| Plugin | Page |
| --- | --- |
| `ai-metadata` | [AI Metadata](../for-administrators/plugin-manager/ai-metadata.md) — connection settings and the four provider types. A [tutorial](../tutorials/ai-metadata-plugin.md) covers the end-to-end workflow. |
| `fylr-plugin-connector` | [Connector](../for-administrators/plugin-manager/connector.md) — searching across other fylr and easydb instances. |
| `fylr-plugin-drupal` | [Drupal](../for-administrators/plugin-manager/drupal.md) — publishing fylr assets into Drupal. What it looks like for the [end user](../for-users/additional-features/drupal-integration.md). |
| `formula-columns` | [Formula Columns](../for-administrators/plugin-manager/formula-columns/README.md) — computing a column's value from a JavaScript snippet, with [examples](../for-administrators/plugin-manager/formula-columns/examples/README.md). |
| `pdf-creator` | [PDF Creator](../tutorials/pdf-creator.md) — installing it, creating a template, printing. |
| `fylr-plugin-typo3` | [TYPO3](../tutorials/typo3-plugin.md) — using fylr images in a TYPO3 site. |
| `fylr-plugin-wordpress` | [WordPress](../for-administrators/plugin-manager/wordpress.md) — transferring images into the WordPress media gallery. |
| `fylr-plugin-zooniverse-import` | [Zooniverse](../for-administrators/plugin-manager/zooniverse.md) — importing Zooniverse CSV exports into records. |

Drupal, TYPO3 and WordPress are **licensed** plugins: your fylr licence has to grant them by name before they can be enabled. See [License management](../license-management.md).
